# 江南计划 - 目标管理小程序

一个专注于目标管理和计划追踪的小程序，帮助用户制定、执行和回顾个人计划。

## 🎯 核心功能

### 1. 宇宙枢纽（个人中心）
- **个人卡片**：展示用户基本信息、头像、个性标签
- **我的计划库**：系统提供的计划模板，按场景分类
- **记事本**：记录想法和笔记
- **心愿单**：纯计划记录，不纳入目标统计
- **换皮肤**：主题切换功能
- **小工具**：计时器等实用工具
- **数据概览**：个人计划完成情况统计
- **代做计划**：为他人创建计划
- **帮助中心**：使用帮助和反馈

### 2. 意念合一（专注功能）
- **今日计划概览**：查看当天所有计划
- **专注计时器**：为计划执行提供计时功能
- **计划状态管理**：开始、暂停、完成计划
- **专注统计**：记录总专注时间和完成情况
- **快速添加计划**：快速创建新计划

### 3. 记忆胶片（日历视图）
- **日历展示**：按月查看计划分布
- **日期选择**：点击日期查看具体计划
- **计划状态标记**：用颜色区分完成情况
- **历史回顾**：查看过去日期的计划完成情况
- **快捷添加**：为选中日期添加计划

### 4. 我的日程（今日计划）
- **计划列表**：瀑布流展示当日计划
- **状态切换**：完成、失败、待定状态管理
- **视图切换**：按天、按月、按年查看
- **完成提示**：全部完成时显示鼓励信息
- **计划创建**：快速添加新计划

## 🚀 技术栈

- **框架**：Taro + React
- **样式**：Tailwind CSS
- **语言**：TypeScript
- **状态管理**：React Hooks
- **构建工具**：pnpm

## 📱 页面结构

```
src/
├── pages/
│   ├── cosmicHubPage/          # 宇宙枢纽（个人中心）
│   ├── focusOnPage/            # 意念合一（专注功能）
│   ├── memoryFilmPage/         # 记忆胶片（日历视图）
│   ├── mySchedulePage/         # 我的日程（今日计划）
│   ├── createPlanPage/         # 创建计划页面
│   ├── planLibraryPage/        # 计划库页面
│   └── analyticsPage/          # 数据概览页面
├── components/
│   ├── tabBar/                 # 底部导航栏
│   └── common/                 # 通用组件
├── utils/
│   └── planUtils.ts            # 计划相关工具函数
├── types/
│   └── plan.d.ts               # 计划相关类型定义
└── routes/
    └── index.ts                # 路由配置
```

## 📋 计划功能

### 计划类型
- **学习**：📚 知识获取和技能提升
- **工作**：💼 工作任务和职业发展
- **健身**：🏃‍♂️ 身体健康和运动
- **生活**：🏠 日常生活和家庭
- **娱乐**：🎮 休闲娱乐活动
- **其他**：📝 其他类型计划

### 重复类型
- **不重复**：一次性计划
- **每天**：每日重复
- **每周**：每周重复
- **每月**：每月重复
- **每年**：每年重复

### 计划状态
- **待完成**：计划创建但未开始
- **进行中**：正在执行的计划
- **已完成**：成功完成的计划
- **未完成**：未能完成的计划

## 🎯 使用流程

1. **创建计划**：在日程页面点击"+"按钮创建新计划
2. **选择模板**：在计划库中选择合适的模板快速开始
3. **执行计划**：在意念合一页面开始专注执行
4. **记录进度**：在日历视图中查看历史记录
5. **数据分析**：在数据概览中查看个人统计
